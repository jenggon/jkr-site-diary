# NGAMSOI UI Grammar

Status: N05R.4 harmony contract.

## Brand
- The current canonical NGAMSOI mark is immutable. Do not redraw, reinterpret or substitute its geometry.
- Header, app icon and completion ritual must reuse the same mark source/family.

## Record sections
- Every Daily Entry section uses one visible, concise heading.
- Heading grammar: orange datum dash + one-word Bahasa Melayu label where practical.
- Canonical labels: `SUMBER`, `HARIAN`, `TAPAK`, `PEKERJA`, `CATATAN`.
- Do not stack a kicker and a duplicate title for the same concept.

## Spine
- Nodes are circular.
- No persistent `NEXT`, `CURRENT`, `EST`, `CHECK` text beside the rail.
- Neutral = not established, orange = currently edited, green = locally established, red = attention/error.
- Shape + state colour carry the meaning; the rail remains continuous.

## Workforce
- Header matrix: `TRED | B | BB | A | JUMLAH`.
- `JUMLAH` is a first-class final column and the overall hardhat total aligns to that authority edge.
- Tapping B/BB/A opens one row-local controller only.
- Controller keeps classification + trade context on one line where space permits.
- Stepper controls are tactile 44px+ targets and do not shift the table columns.

## Operational source
- Selected MSP or VO/APK is one loaded source instrument, not a nested card/folder metaphor.
- `Tukar` is always a visible secondary action docked predictably to the selected source.

## Project header
- Project nickname and official title remain primary identity.
- Project pulse may show only meaningful authoritative/live context. Current contract: current revision, days to project finish, device time.
- Do not show fake task counts or inferred programme metrics without an authoritative projection.

## Navigation
- `Baharu`: create a new daily entry.
- `Aktiviti`: continue work activities that remain open/in progress.
- `Rekod`: saved Site Diary records/history.
- `Semak`: approval/review queue according to user capability.
- Collapsed desktop rail hugs the icon; expanded labels must not change the underlying information architecture.

## Onboarding
- First-use tutorial must teach this exact grammar.
- Tutorial callouts must point to the same controls and terminology used in normal runtime.
- No tutorial-only labels, colours, metaphors or alternate navigation names.
