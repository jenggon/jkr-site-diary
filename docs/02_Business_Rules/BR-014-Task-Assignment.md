# BR-014: Task Assignment

**Project:** JKR Site Diary Platform
**Version:** 1.0.0

Status: Locked

Priority: High

## Purpose

Assign Tasks for operational execution.

## Rule Statement

Each Task may only belong to one Program Kerja.

Task ownership shall remain unchanged throughout execution.

## Acceptance Criteria

- Task assigned.
- Ownership preserved.
