# BR-012: MSP Import

**Project:** JKR Site Diary Platform
**Version:** 1.0.0

Status: Locked

Priority: Critical

## Purpose

Define Microsoft Project import behaviour.

## Rule Statement

Imported MSP files shall be validated before Programme creation.

Import failures shall not modify existing operational data.

## Acceptance Criteria

- MSP validated.
- Import completed.
- Invalid import rejected.
