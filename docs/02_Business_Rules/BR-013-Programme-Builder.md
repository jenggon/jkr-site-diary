# BR-013: Programme Builder

Status: Active

Priority: High

## Purpose

Generate Program Kerja from an Approved Programme Revision.

## Rule Statement

Programme Builder shall transform planning data into operational structures.

Generated Tasks shall preserve original planning identifiers.

## Acceptance Criteria

- Program Kerja generated.
- Tasks generated.
- UID preserved.
