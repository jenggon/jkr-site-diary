# BR-007: Site Diary

**Project:** JKR Site Diary Platform
**Version:** 1.0.0

Status: Locked

Priority: Critical

## Purpose

Define Site Diary behaviour.

## Rule Statement

Exactly one Site Diary shall exist for each project date.

A Site Diary records Activities, Workforce, Progress, Weather and operational remarks.

Approved Site Diary records become immutable.

## Acceptance Criteria

- Daily Site Diary created.
- Operational records saved.
- Site Diary approved.
