# BR-006: Open Activity

Status: Active

Priority: Critical

## Purpose

Define Open Activity lifecycle.

## Rule Statement

An Activity that has not been completed shall remain an Open Activity.

Open Activities shall automatically appear in subsequent Site Diary entries until officially closed.

Only one active Open Activity record may exist for the same Activity.

## Acceptance Criteria

- Activity opened.
- Activity continues across multiple days.
- Activity closed successfully.
