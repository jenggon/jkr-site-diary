# BR-004: Task

**Project:** JKR Site Diary Platform
**Version:** 1.0.0

Status: Locked

Priority: High

## Purpose

Define Task registration.

## Rule Statement

Every Task belongs to exactly one Program Kerja.

Task UID shall remain immutable.

Tasks may contain multiple Activities.

## Acceptance Criteria

- Task imported.
- UID preserved.
- Activities linked.
