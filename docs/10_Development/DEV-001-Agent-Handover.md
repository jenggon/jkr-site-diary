# DEV-001 — Agent Handover Standard

## Status

Approved

---

# Purpose

Provide a standard handover process between AI agents and human contributors.

---

# Objective

Ensure work continues without loss of context whenever an agent becomes unavailable.

---

# Handover Trigger

Agent reaches token limit.

Conversation reset.

Model unavailable.

Task reassigned.

Sprint completed.

---

# Mandatory Handover

Every handover shall include:

Completed Work

Remaining Work

Known Issues

Risks

Recommended Next Action

Related Specifications

Affected Files

---

# Handover Template

Current Task

Task Status

Completed

Remaining

Dependencies

Blocking Issues

Suggested Next Owner

Expected Deliverables

---

# Rules

Never leave undocumented work.

Never assume the next contributor has previous context.

Always reference official specifications.
