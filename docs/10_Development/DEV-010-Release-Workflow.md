---

# Pre-Release Checklist

Build successful.

All tests passed.

Documentation updated.

Database migrations verified.

Security review completed.

Version updated.

Release notes prepared.

---

# Release Approval

Product Owner approval.

Architecture approval.

Quality verification completed.

---

# Post Release

Verify deployment.

Monitor logs.

Monitor performance.

Confirm business functionality.

Document issues if found.

---

# Rollback

Rollback must follow documented rollback procedure.

Every release shall have a recovery plan.
