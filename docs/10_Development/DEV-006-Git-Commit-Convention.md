# DEV-006 — Git Commit Convention

**Version:** 1.0.0
**Project:** JKR Site Diary Platform

## Status

Locked

---

# Purpose

Standardise commit history across the project.

---

# Format

type(scope): description

---

# Types

docs

feat

fix

refactor

style

test

perf

build

ci

chore

revert

---

# Examples

docs(api): add activity API

feat(activity): implement repository

fix(database): resolve foreign key

refactor(ui): simplify dashboard layout

test(api): add integration tests

---

# Rules

One logical change per commit.

Commit after successful verification.

Avoid mixed-purpose commits.

Meaningful descriptions only.

---
