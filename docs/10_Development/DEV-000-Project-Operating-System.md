# DEV-000 — Project Operating System

## Status

Approved

---

# Purpose

Define the operational model governing how the JKR Site Diary platform is designed, developed, reviewed, tested and released.

This document establishes the working constitution for both human contributors and AI agents.

---

# Principles

The project shall be developed through documented specifications before implementation.

Every architectural decision shall be traceable.

Every implementation shall reference an approved specification.

No implementation shall bypass Business Rules.

No AI shall become the single source of knowledge.

Artifacts are permanent.

Conversations are temporary.

---

# Development Philosophy

Specification First

Architecture Driven

Database Before API

API Before UI

UI Before Integration

Review Before Merge

Automation Before Repetition

Documentation Before Assumption
