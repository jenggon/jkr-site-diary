## Bounded remediation

### F45-CSS-001 — single runtime authority

The declaration order that previously existed as:

`ngamsoi-f45-harmony.css` → `ngamsoi-f45-seal.css` → `ngamsoi-f45-authority.css`

is consolidated into `src/app/ngamsoi-f45-authority.css` in the same order. `src/app/layout.tsx` now imports only `ngamsoi-f45-authority.css` for F4.5.

Provenance of the frozen source inputs at BASE_HEAD:

- former harmony blob: `5f89d862d3b412eacca42bc9c63c591020461b15`
- former seal blob: `17f5dbdb2117fd81edf7b6d74af84aaf41840a17`
- prior final authority blob: `5ca10b0139afdabd33aab73093e59a81720fe1d0`

The standalone former harmony/seal files remain in the repository as historical references only and are no longer imported by application runtime. No fourth visual layer or CSS `@import` chain is introduced.

A new executable regression guard `tests/integration/ui/f45AuthorityOwnership.test.ts` requires:

- exactly one direct `ngamsoi-f45-*.css` import in `src/app/layout.tsx`;
- that import to be `ngamsoi-f45-authority.css`;
- the authority to be self-contained with no F4.5 CSS `@import` chain.

### F45-HDR-002 — runtime readability evidence

`expectCoreHeader()` keeps all existing visibility and forecast-policy assertions, and additionally evaluates the four core pulse facts in-browser for:

- child text bounds staying inside each fact cell;
- no `text-overflow: ellipsis` or active line-clamp on the fact text;
- no scroll-size clipping of the fact cell;
- non-empty visible fact content.

The same helper runs at wide desktop, half-window and phone viewports.

### F45-GEO-001 — post-save runtime evidence

The Playwright-owned acceptance fixture is extended only with the exact mutation responses required to complete the existing CATAT save flow:

- `POST /api/activities`;
- `POST /api/activities/:activityId/start`;
- `POST /api/site-diary`.

Payloads are validated and unexpected calls continue to fail closed. No production route, auth bypass, provider override, or live mutable dependency is introduced.

The phone browser case now performs real UI input and a real Save click, waits for the persistent post-save confirmation, asserts both actions are visible, and checks computed `border-radius: 0px` on:

- `.ng-post-save`;
- `.ng-post-save__actions`;
- both post-save action buttons.

The general sharp-geometry helper also includes these selectors whenever they are visible.
