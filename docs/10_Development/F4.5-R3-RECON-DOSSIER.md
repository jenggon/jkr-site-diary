## Root-cause map

1. **Recurring green line / dashboard accent** — legacy consolidated authority still contains `data-pulse='programme'` green styling and older pulse geometry. Round-2 post-physical CSS neutralised some placement rules but did not retire every green/progress visual owner. Fix must remove/neutralise green from non-completion dashboard/header concerns rather than layer another accidental accent.
2. **PROGRAM KERJA perceived duplicate** — current markup has one semantic `<small>PROGRAM KERJA</small>` and value `Rxx`; therefore the physical duplicate is treated as a rendering/legacy-authority recurrence rather than intended duplicate markup. Proving must count the rendered label and assert the value excludes the label.
3. **Nested SUMBER** — `CatatEntryForm` owns the accepted outer `SUMBER` heading while expanded `OperationalSourceSelector` still owns an internal `Sumber Aktiviti` header block. Remove the nested section-title block while preserving MSP / VO-APK source-type labels and selected metadata.
4. **Mula sebenar helper wrap** — current exact copy is `Tarikh sebenar kerja mula di tapak.`; shorten to locked `Tarikh kerja mula di tapak.` and keep it as a lightweight field helper.
5. **MULA + SIAP discoverability** — state machine already supports `MULA_DAN_SIAP` through toggle logic, but no persistent user guidance remains after the old green pseudo-success note was removed. Add non-green contextual guidance under/with the status control.
6. **Completion Seal dismiss defect** — `PostSaveConfirmation` owns `dismissed` locally. After dismiss it still renders only a disabled `Disimpan` final-step button, while `CatatEntryForm` disables every form field whenever `successId` is set. This technically preserves immutability but presents a hung editor. Replace the collapsed state with an explicit saved receipt surface containing `Disimpan`, `Tunjuk Rekod`, and `Tambah Aktiviti`; keep the editor immutable and visually subordinate rather than presenting disabled controls as the primary post-dismiss experience.
7. **Close geometry parity** — Completion Seal uses a bespoke `.ng-completion-seal__close`; VO/APK uses `.ng-vo-dialog__close` from the existing modal header. Introduce one shared square close-control geometry rule that targets both classes; preserve modal semantics and layering.
8. **Forecast availability** — `ProjectWeatherPulse` requires an authenticated session then calls `/api/weather/site?mode=forecast`. The API returns 503 when `VISUAL_CROSSING_API_KEY` is absent. `.env.example` intentionally leaves that server-only key blank. Physical `Tiada data` therefore reflects configuration/unavailable state. Change user copy to `Ramalan belum tersedia`; do not fabricate preview/live weather and do not change provider/domain authority.
