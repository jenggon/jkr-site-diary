# Purpose

Progress records the measured achievement of an Activity.

Progress represents work completed.

Progress does not own Activity lifecycle.

Progress does not replace Site Diary.

# Business Rules

Progress belongs to one Activity.

Progress belongs to one Site Diary.

Progress records measurable work only.

Progress never changes Task Definition.

Progress never changes Programme Revision.

Approved Progress becomes read-only.

Progress may be revised only while Draft.
