# DB-018
# Trade Library Schema

Status

Approved

---

# Purpose

Trade Library is the master reference for all recognised construction trades used throughout the system.

Trade Library provides a consistent classification of workforce trades across all Programmes.

Trade Library stores administrative reference data only.

Trade Library never stores operational workforce records.

# Business Rules

Trade Library is shared across all Programmes.

Trade names should remain stable.

Trade Code must be unique.

Inactive trades remain available for historical reporting.

Trade Library stores master reference data only.

Trade Library shall not contain operational workforce quantities.
