# Purpose

Resource Assignment records the planned workforce allocation for a Task within a Programme Revision.

Resource Assignment represents planning data imported from Microsoft Project or other approved planning systems.

Resource Assignment is used for comparison between planned resources and actual workforce execution.

Resource Assignment does not record actual attendance or site execution.

# Business Rules

Each Resource Assignment belongs to one Task.

Each Resource Assignment belongs to one Programme Revision.

Each trade shall appear only once for each Task.

Resource Assignment represents planning baseline only.

Operational Workforce shall never modify Resource Assignment.

New Programme Revision creates a new Resource Assignment baseline.

Historical revisions remain unchanged.
