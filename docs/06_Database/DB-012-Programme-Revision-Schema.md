# Programme Revision Schema

**Project:** JKR Site Diary Platform
**Version:** 1.0.0

Status

Locked

---

# Purpose

Programme Revision represents an approved planning baseline for a Programme.

Each revision captures a complete planning snapshot imported from Microsoft Project (MSP).

Operational data shall always reference exactly one approved Programme Revision.

A new revision creates a new operational cycle.

Existing operational records are never migrated to another revision.

# Business Rules

Every Programme Revision belongs to one Programme.

Revision numbers restart for each Programme.

Approved revisions are immutable.

Draft revisions may be modified.

Archived revisions are read-only.

Operational records must never move to another revision.

Creating a new revision shall not modify historical operational data.

Only one current revision may exist per Programme.
