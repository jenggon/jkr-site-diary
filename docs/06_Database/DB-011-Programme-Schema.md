# DB-011
# Programme Schema

Status

Approved

---

## Purpose

Programme is the root aggregate of the JKR Site Diary Platform.

Every operational entity ultimately belongs to exactly one Programme.

This table represents the highest ownership boundary within the system.

No operational record may exist without an owning Programme.

---

# Table Name

programme

---

# Primary Key

UUID

Immutable.

Never reused.

# Business Identity

# Business Rules

Programme Code must be unique.

Programme cannot be physically deleted.

Programme may only be archived.

Every operational record belongs to exactly one Programme.

Programme may have many revisions.

Only one revision may be Current.

Programme ownership never changes.
