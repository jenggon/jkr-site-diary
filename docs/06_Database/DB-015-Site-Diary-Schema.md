# Site Diary Schema

Status

Approved

---

# Purpose

Site Diary records the daily execution log for an Activity.

A Site Diary does not own operational state.

Operational state belongs to Activity.

Site Diary records what happened on a specific day.

# Business Rules

One Site Diary represents one Activity for one operational day.

Multiple diary entries for the same Activity on the same date are prohibited.

Site Diary records daily execution only.

Site Diary shall not modify Task.

Site Diary shall not modify Programme Revision.

Activity determines operational lifecycle.
