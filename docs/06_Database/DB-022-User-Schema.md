# Purpose

User stores application user profiles and identity information.

Authentication is delegated to Supabase Auth.

User stores business identity, Programme membership and application profile.

# Business Rules

Authentication is managed by Supabase Auth.

Business profile is managed by User Profile.

Inactive users cannot access the system.

Historical ownership shall remain after user deactivation.
