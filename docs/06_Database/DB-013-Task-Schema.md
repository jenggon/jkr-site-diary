# DB-013
# Task Schema

Status

Approved

---

# Purpose

Task represents the imported planning activities from Microsoft Project (MSP).

Tasks define the official planning structure for a Programme Revision.

Tasks are immutable after the associated Programme Revision has been approved.

Tasks do not record execution progress.

Execution is recorded by Activities.

# Business Rules

Task originates only from MSP import.

Users cannot manually create Tasks.

Users cannot edit approved Tasks.

Task hierarchy must remain valid.

Task UID is unique within a Revision.

Deleting Tasks is prohibited.

New Programme Revision imports a completely new Task set.
