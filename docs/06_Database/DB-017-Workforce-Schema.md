# Purpose

Workforce records the manpower assigned to an Activity for a specific Site Diary.

Workforce stores structured labour records.

Workforce replaces embedded manpower JSON storage.

Each trade is stored as an individual database record.

# Business Rules

Each Workforce record represents one trade.

One trade shall appear only once within one Site Diary.

Workforce records are historical snapshots.

Changes to Trade Library shall not affect historical Workforce records.

Workforce does not determine Activity Status.
