# G-001: Program Kerja

## Definition

Program Kerja is the officially approved operational planning package that forms the boundary between Zon Penjadualan and Zon Operasi.

It is generated from an Approved Programme Revision and becomes the only planning reference consumed by operational components.

---

## Characteristics

- Official operational planning package.
- Generated from an Approved Programme Revision.
- Single Source of Truth (SSOT).
- Read-only after publication.
- Versioned.
- Traceable.

---

## Ownership

Owned by Zon Penjadualan.

Consumed by Zon Operasi.
