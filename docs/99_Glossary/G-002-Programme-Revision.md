# G-002: Programme Revision

## Definition

A Programme Revision represents a formally approved planning baseline for a project.

Each revision defines the complete planning state used to generate one Program Kerja.

---

## Lifecycle

Draft

↓

Approved

↓

Archived

Only one revision may hold Approved status at any given time.

---

## Characteristics

- Version controlled.
- Immutable after approval.
- Historical.
- Traceable.

---

## Ownership
