# JKR Site Diary Glossary

## Purpose

This glossary defines the official terminology used throughout the JKR Site Diary Platform.

Every architecture document, business rule, API specification, database schema and source code shall use the terms defined in this glossary.

The objective is to establish a single ubiquitous language shared by business users, developers, testers and architects.

# Naming Principles

Every glossary entry shall:

- Have one official definition.
- Avoid ambiguity.
- Be technology independent.
- Be reusable across the platform.
- Remain stable whenever possible.

---

# Entry Template

Each glossary entry shall contain:

- Term
- Definition
- Owner
- Related Documents
- Notes
