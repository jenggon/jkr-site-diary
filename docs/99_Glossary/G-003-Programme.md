# G-003: Programme

## Definition

A Programme is the complete planning structure of a construction project.

It contains all planning information required to execute the project, including tasks, sequencing, durations, dependencies and revisions.

---

## Characteristics

- High-level planning entity.
- May contain multiple revisions.
- Exists throughout the project lifecycle.
