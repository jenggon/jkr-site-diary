# 1. Purpose

This document serves as the master index for every reusable UI component within the JKR Site Diary Platform.

Unlike component specifications, this document acts as the primary navigation reference for the design system.

It shall be updated whenever a component is introduced, renamed, deprecated or removed.

---

# 2. Objectives

The Component Library Index shall:

- Provide a complete inventory of all UI components.
- Organise components by architectural category.
- Improve discoverability.
- Prevent duplicate component creation.
- Support architecture governance.
- Provide implementation status tracking.

---

# 5. Component Lifecycle

Each component shall adopt one of the following lifecycle states:

- Planned
- Draft
- In Review
- Approved
- Implemented
- Deprecated
- Retired

---

# 6. Governance Rules

- Every component shall have a unique Document ID.
- Every component shall reference UI-199, UI-199A and UI-199B.
- Duplicate functionality is prohibited.
- Component status shall be maintained.
- Deprecated components shall remain listed until officially retired.

---

# 7. Future Expansion

New categories may be introduced through architectural review.

Existing numbering shall remain stable.
