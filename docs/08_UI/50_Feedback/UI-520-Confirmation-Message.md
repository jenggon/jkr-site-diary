# Purpose

Requests explicit user confirmation before executing significant or irreversible actions.

---

# Features

- Confirmation Text
- Primary Action
- Secondary Action
- Warning State
- Optional Checkbox

---

# Typical Uses

- Delete Record
- Submit Approval
- Archive Project
- Reset Form
- Remove Attachment

---

# Behaviour

Confirmation shall only be requested for actions with meaningful consequences.
