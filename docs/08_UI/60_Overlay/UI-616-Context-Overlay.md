# Purpose

Displays temporary contextual content related to the currently selected object without interrupting workflow.

---

# Features

- Dynamic Content
- Anchored Display
- Responsive Positioning
- Permission-aware Actions

---

# Typical Uses

- Activity Preview
- Drawing Information
- Attachment Preview
- Project Summary

---

# Behaviour

Context overlays shall close automatically when focus is lost unless configured otherwise.
