# UI-619 - Loading Overlay

| Document ID | UI-619 |
|-------------|---------|
| Title | Loading Overlay |
| Version | 1.0.0 |
| Status | LOCKED |

---

# Purpose

Temporarily blocks user interaction while a critical operation is executing.

---

# Features

- Spinner
- Progress Indicator
- Optional Message
- Cancel Support
- Timeout Handling

---

# Typical Uses

- Save Project
- Import Programme
- Synchronisation
- Large File Upload

---

# Behaviour

Loading overlays shall only be used for operations that prevent safe user interaction.
