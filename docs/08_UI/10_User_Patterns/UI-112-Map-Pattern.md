# 1. Purpose

Defines map-based interaction throughout the platform.

Maps provide geographical awareness for construction activities.

---

# 2. Objectives

The Map Pattern shall:

- Improve spatial awareness.
- Support location-based records.
- Visualise project assets.
- Assist field operations.

---

# 3. Map Layers

Project Boundary

Structures

Roads

Utilities

Photos

Activities

Equipment

Weather

---

# 4. Supported Operations

Zoom

Pan

Locate User

Select Object

Filter Layers

Measure Distance (Future)

---

# 5. Map States

Loading

Ready

Offline

Error

GPS Active

---

# 6. Mobile Behaviour

Support GPS positioning.

Optimise for one-handed operation.

---

# 7. AI Behaviour

Future AI may:

Suggest nearby activities.

Detect location conflicts.

Recommend inspection routes.

---

# 8. Accessibility

Maps shall provide list alternatives where practical.
