# 1. Purpose

Defines the standard presentation of audit information across the platform.

Audit trails provide accountability and traceability for operational records.

---

# 2. Audit Information

Every audit entry should include:

User

Timestamp

Action

Previous Value (where applicable)

New Value (where applicable)

Source

---

# 3. Rules

Audit records are immutable.

Audit history shall be searchable.

Audit records shall remain linked to originating records.

---

# 4. AI Behaviour

AI-generated actions shall be clearly identified.
