# 1. Purpose

Defines the universal command interface for the JKR Site Diary Platform.

The Command Palette enables users to navigate, search and execute actions without relying on traditional menu navigation.

---

# 2. Objectives

The Command Palette shall:

- Reduce navigation time.
- Improve keyboard productivity.
- Centralise common actions.
- Support AI-assisted workflows.

---

# 3. Activation

Desktop

Ctrl + K

Mobile

Search Button

Long Press (Future)

Voice (Future)

---

# 4. Supported Commands

Open Project

Open Activity

Create Site Diary

Search

Upload Photo

Approve Record

Generate Report

---

# 5. Search Behaviour

Commands shall support:

Partial Match

Fuzzy Match

Recent Commands

Favourite Commands

---

# 6. AI Behaviour

Future AI may:

Recommend commands.

Predict next actions.

Generate contextual shortcuts.

---

# 7. Accessibility

Fully keyboard accessible.

Screen reader compatible.
