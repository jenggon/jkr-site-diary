# 1. Purpose

The Date Picker component enables users to select a single calendar date using either direct input or an interactive calendar.

---

# 2. Features

- Calendar Popup
- Manual Date Entry
- Min / Max Date
- Disabled Dates
- Default Date
- Today Shortcut
- Clear Selection

---

# 3. States

- Default
- Focus
- Selected
- Disabled
- Error
- Read Only

---

# 4. Typical Uses

- Site Diary Date
- Inspection Date
- Approval Date
- Work Completion Date

---

# 5. Accessibility

Supports keyboard navigation, screen readers and semantic calendar controls.
