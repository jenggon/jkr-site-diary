---

# Purpose

Allows the user to select exactly one option from a predefined group.

---

# Behaviour

- Only one option may be selected.
- Selecting another option clears the previous selection.
- Radio Buttons shall always belong to a logical group.

---

# States

- Selected
- Unselected
- Disabled
- Error

---

# Typical Uses

- Status selection
- Category selection
- Configuration choices
