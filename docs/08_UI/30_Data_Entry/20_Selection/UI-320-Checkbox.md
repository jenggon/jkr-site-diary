# 1. Purpose

The Checkbox component allows users to independently select one or more options from a predefined list.

---

# 2. Behaviour

A Checkbox shall:

- Support multiple selections.
- Operate independently of other checkboxes unless grouped.
- Preserve state until changed by the user or application logic.

---

# 3. States

- Unchecked
- Checked
- Indeterminate
- Disabled
- Error

---

# 4. Typical Uses

- Agreement confirmation
- Multiple option selection
- Feature enablement
- Task completion

---

# 5. Accessibility

Supports keyboard interaction, semantic labels and assistive technologies.
