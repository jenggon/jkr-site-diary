# 1. Purpose

The Text Field component captures a single line of textual input from users.

It is the default component for entering structured text such as names, IDs, titles and short descriptions.

---

# 2. Supported Data

- Text
- Numbers (display only)
- Alphanumeric
- Codes
- IDs

---

- Filled

- Read Only
- Disabled
