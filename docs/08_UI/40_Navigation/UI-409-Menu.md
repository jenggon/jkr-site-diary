# 1. Purpose

Provides a structured list of actions or navigation destinations within a contextual container.

---

# 2. Features

- Vertical Menu
- Horizontal Menu
- Nested Menu
- Section Divider
- Icons
- Keyboard Navigation
- Disabled Items

---

# 3. Behaviour

The Menu shall:

- Highlight hover and active items.
- Support nested groups.
- Close automatically after action selection (configurable).

---

# 4. Typical Uses

- User Menu
- Module Menu
- Toolbar Actions
- Overflow Actions

---

# 5. Accessibility

Supports arrow-key navigation, Enter/Space activation and screen readers.
