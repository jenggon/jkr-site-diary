# Purpose

Defines accessibility requirements for all dialog-based interactions.

---

# Requirements

- Initial Focus
- Focus Trap
- Escape Key Support
- Accessible Title
- Accessible Description
- Focus Restore

---

# Typical Uses

- Confirmation Dialog
- Delete Dialog
- Approval Dialog
- Error Dialog

---

# Behaviour

Dialogs shall trap keyboard focus until dismissed.
