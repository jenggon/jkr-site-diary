# Purpose

# Testing Checklist

- Keyboard Navigation
- Screen Reader Compatibility
- Colour Contrast
- Focus Indicators
- Responsive Accessibility
- Reduced Motion
- Form Validation

---

# Validation

Accessibility shall be verified during every major release.
