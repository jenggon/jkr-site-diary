# Purpose

Defines accessibility requirements for enterprise data tables.

---

# Requirements

- Header Associations
- Keyboard Navigation
- Sort Announcements
- Responsive Behaviour
- Screen Reader Compatibility

---

# Typical Uses

- Reports
- Registers
- Audit Logs
- Activity Lists

---

# Behaviour

Tables shall expose semantic headers and relationships for assistive technologies.
