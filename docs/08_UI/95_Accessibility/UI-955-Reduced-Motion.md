# UI-955 - Reduced Motion

| Document ID | UI-955 |
|-------------|---------|
| Title | Reduced Motion |
| Version | 1.0.0 |
| Status | LOCKED |

---

# Purpose

Provides alternatives for users who prefer reduced interface motion.

---

# Features

- Disable Non-essential Animation
- Reduce Transition Effects
- Preserve Context
- Respect System Preference

---

# Typical Uses

- Navigation
- Dialogs
- Page Transitions
- Loading Indicators

---

# Behaviour

Applications shall respect the operating system's reduced motion preference.
