# 1. Purpose

Defines the accessibility architecture governing all user interfaces within the JKR Site Diary platform.

---

# 2. Objectives

The Accessibility Architecture shall:

- Support keyboard-only operation.
- Support assistive technologies.
- Ensure readable interfaces.
- Meet enterprise accessibility requirements.
- Maintain accessibility across desktop and mobile.
- Encourage inclusive design.

---

# 3. Scope

This architecture governs:

- Keyboard Navigation
- Focus Management
- Screen Reader Support
- Colour & Contrast
- Motion Reduction
- Accessible Forms
- Accessible Tables
- Accessible Dialogs

---

# 4. Design Principles

## Perceivable

Information shall remain visible and understandable.

---

## Operable

All functions shall be operable without a mouse.

---

## Understandable

User interfaces shall behave consistently.

---

## Robust

Interfaces shall support assistive technologies.
