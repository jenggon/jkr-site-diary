# Database Migration Standard

## Status

Approved

---

# Purpose

Defines migration rules.

---

# Principles

Database First.

Version Controlled.

Repeatable.

Auditable.

---

# Rules

Never modify production manually.

Every schema change requires migration.

Migration filenames shall be timestamped.

Rollback shall be considered.

---

# Validation

Migration tested.

Schema verified.

Documentation updated.
