# PB-001 — Programme Builder

**Version:** 1.0.0
**Project:** JKR Site Diary Platform

## Status

Locked

---

# Purpose

Transform an approved Programme Revision into an executable Program Kerja.

Programme Builder is the publication engine between planning and operations.

---

# Responsibilities

- Read approved Programme Revision
- Validate planning integrity
- Generate Program Kerja
- Generate Task hierarchy
- Generate UID mapping
- Publish operational package

---

# Inputs

- Approved Programme
- Approved Programme Revision
- MSP Task Structure

---

# Outputs

- Program Kerja
- Task Structure
- UID Mapping
- Operational Package

---

# Owns

- Program Kerja generation process

---

# Does NOT Own

- Site Diary
- Activity
- Progress
- Workforce
