# PB-006 — APK Integration

**Version:** 1.0.0
**Project:** JKR Site Diary Platform

## Status

Locked

---

# Purpose

Integrate approved APK into Programme planning.

---

# Rules

APK shall create a new Programme Revision.

No direct modification of an existing Revision is permitted.

APK Tasks participate in normal Task generation.

---

# Output

Updated Programme Revision.
