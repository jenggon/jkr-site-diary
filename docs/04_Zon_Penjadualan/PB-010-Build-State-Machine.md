# State Machine

```
Draft
   │
   ▼
Validated
   │
   ▼
Building
   │
   ▼
Published
```

---

# Failure Path

```
Draft
   │
   ▼
Validated
   │
   ▼
Failed
```

---

# Constraints

Publishing is irreversible.

A Published operational package becomes the official Program Kerja until replaced by a newer published Revision.
