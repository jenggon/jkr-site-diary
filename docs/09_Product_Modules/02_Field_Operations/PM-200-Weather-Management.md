# PM-200 — Weather Management

**Version:** 1.0.0
**Project:** JKR Site Diary Platform

## Status

Locked

# Purpose

Capture official daily weather conditions affecting construction operations.

---

# Business Objective

Provide objective weather evidence for project records, claims and progress analysis.

---

# Business Value

- Improve contractual evidence.
- Support Extension of Time (EOT) assessments.
- Explain productivity fluctuations.
- Reduce manual weather recording.

---

# Actors

Primary

- Site Engineer

Secondary

- Resident Engineer
- Project Manager

# Functional Scope

Included

- Current weather
- Temperature
- Humidity
- Rainfall
- Wind
- Manual remarks

Excluded

- Forecast planning
- Climate analytics

# User Stories

As a Site Engineer,

I want today's weather captured automatically,

so that I do not need to manually record environmental conditions.

---

# Functional Requirements

Automatic retrieval.

Manual verification.

Historical weather immutable.

Linked to Site Diary.
