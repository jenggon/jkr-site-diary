# PM-204 — Resource Assignment

**Version:** 1.0.0
**Project:** JKR Site Diary Platform

## Status

Locked

---

# Purpose

Coordinate assignment of labour, equipment and materials to construction activities.

---

# Business Objective

Provide a complete operational resource allocation model for every construction activity.

---

# Business Value

Improve planning accuracy.

Reduce idle resources.

Provide complete resource traceability.

Support productivity analysis.

---

# Actors

Primary

- Site Engineer
- Project Manager

Secondary

- Resident Engineer

---

Validate

↓

Save

↓

Monitor

# Functional Scope

Included

- Workforce assignment
- Equipment assignment
- Material assignment
- Assignment history

Excluded

- Procurement
- Payroll

---

# Functional Requirements

Assignment belongs to one Activity.

Assignment history immutable.

Multiple resources supported.
