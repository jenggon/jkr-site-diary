Pursuant to the **HQ Architecture Decision (C09-D)** following the C09-C read-authority reconnaissance findings, all externally reachable Progress HTTP routes have been placed into an intentional, fail-closed dormant state returning uniform HTTP `404` (`{ "error": "Not Found" }`).

## 2. HQ Architecture Decision

C09-C established:
1. Progress is **NOT** required for current F2 / B03 product scope.
2. Progress quantity carry-forward is deferred.
3. Progress-linked Approval path is deferred.
4. Legacy public `progress` SELECT exposure and caller context defects existed on dormant endpoints.

**HQ Directive:**
- Rather than introducing an ungoverned or premature read-authority architecture (RLS, views, RPCs, or authenticated repository refactoring) for an inactive module, the dormant Progress HTTP surface must **fail closed**.
- Return generic HTTP 404 `{ "error": "Not Found" }` indistinguishably across all caller contexts (unauthenticated, legitimate Programme members, foreign callers).
- Zero database queries, zero service invocations, zero ID parameter probing, and zero state mutation.
- The underlying Progress Engine domain services, composition, repositories, and atomic transactions are preserved without modification.
