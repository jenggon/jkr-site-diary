## 1. Remediation Architecture: Single Request-Scoped Client Composition (Unchanged)

The core authenticated composition remediation is accepted and remains unchanged:
`createSiteDiaryService(accessToken)` in `src/composition/siteDiaryComposition.ts` instantiates exactly ONE Supabase client per factory call:
- When `accessToken` is provided: `getSupabaseAuthenticatedClient(accessToken)`
- When `accessToken` is omitted: `getSupabaseServerClient()`

A single `SupabaseDatabaseAdapter` bound to this client is injected into:
1. `ProgrammeRepository(adapter)`
2. `ProgrammeRevisionRepository(adapter)`
3. `ActivityRepository(adapter)`

The client is also passed to `createSiteDiaryRepository(client)` and `ResidualAtomicRepository(client)`.

```typescript
export function createSiteDiaryService(accessToken?: string): ISiteDiaryService {
  const client = accessToken
    ? getSupabaseAuthenticatedClient(accessToken)
    : getSupabaseServerClient();
  const adapter = new SupabaseDatabaseAdapter(client);

  return new SiteDiaryService({
    programmeRepository: new ProgrammeRepository(adapter),
    revisionRepository: new ProgrammeRevisionRepository(adapter),
    activityRepository: new ActivityRepository(adapter),
    siteDiaryRepository: createSiteDiaryRepository(client),
    clock,
    logger,
    ...(accessToken ? { atomicRepository: new ResidualAtomicRepository(client) } : {}),
  });
}
```

## 2. Corrective Closure: Complete Safe 5xx Route Redaction

Per HQ review finding, internal errors (`UnknownError` or any non-4xx failure) could previously leak `result.error.message` if not matched by specific regexes.

The corrective closure enforces a strict fail-closed contract across `POST /api/site-diary`, `GET /api/site-diary/[siteDiaryId]`, and `PATCH /api/site-diary/[siteDiaryId]`:
- **Known 4xx Domain/Application Errors** (`httpStatus >= 400 && httpStatus < 500`):
  - Preserves canonical `httpStatus` (e.g. 400, 404, 409, 423)
  - Preserves safe domain error message
- **Internal / 5xx / Unknown Errors** (`httpStatus >= 500` or non-4xx):
  - Returns HTTP `500`
  - Generic route-safe message (`Failed to create site diary`, `Failed to retrieve site diary`, `Failed to update site diary`)
  - Never returns `result.error.message` or internal text
  - Covers `InfrastructureError`, `UnknownError`, and future internal 5xx subclasses.
