# F2.7-C09-A: Site Diary Authenticated Prerequisite Read Context Recon

## Mission Objective
Determine whether the authenticated Site Diary create path (`POST /api/site-diary`) loses the caller's auth context during prerequisite reads prior to reaching the atomic mutation boundary.

---

## 1. Static Trace Analysis

### Path Flow
1. **HTTP Endpoint (`src/app/api/site-diary/route.ts`)**:
   - Extracts and verifies caller identity: `identity.accessToken`, `identity.actorId`.
   - Passes `identity.accessToken` to `createSiteDiaryService(identity.accessToken)`.
2. **Composition Root (`src/composition/siteDiaryComposition.ts`)**:
   - Calls `new SiteDiaryService({...})`.
   - Passes `programmeRepository: new ProgrammeRepository()`.
   - Passes `revisionRepository: new ProgrammeRevisionRepository()`.
   - Passes `siteDiaryRepository: siteDiaryRepository` (singleton).
   - Passes `atomicRepository: new ResidualAtomicRepository(getSupabaseAuthenticatedClient(accessToken))`.
   - **Omission**: Does NOT instantiate `ProgrammeRepository`, `ProgrammeRevisionRepository`, `ActivityRepository`, or `siteDiaryRepository` with a request-scoped authenticated database adapter or client.
3. **Domain Service (`src/services/siteDiaryService.ts:createSiteDiary`)**:
   - Evaluates prerequisite reads using unauthenticated / default anonymous clients:
     - `this.programmeRepo.findById(cmd.programmeId)`
     - `this.activityRepo.findById(cmd.activityId)`
     - `this.revisionRepo.findById(cmd.revisionId)`
   - Only the final atomic mutation (`this.atomicRepo.createSiteDiary(...)`) uses the authenticated client.

## 2. Prerequisite Dependency Matrix

| DEPENDENCY | READ OPERATION | CLIENT SOURCE | AUTHENTICATED REQUEST-SCOPED? | CAN AUTHENTICATED DIRECT SELECT LEGALLY ACCESS TABLE? | EXPECTED FAILURE IF ANON |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `programme` | `SELECT * FROM programme WHERE programme_id = ?` | `SupabaseDatabaseAdapter` -> `getSupabaseServerClient()` | **NO** (anon key only) | **YES** (`is_programme_member` policy grants active members) | `42501` (permission denied for table programme) / PostgREST error |
| `activity` | `SELECT * FROM activity WHERE activity_id = ?` | `SupabaseDatabaseAdapter` -> `getSupabaseServerClient()` | **NO** (anon key only) | **YES** (`is_programme_member` policy grants active members) | `42501` (permission denied for table activity) / PostgREST error |
| `programme_revision` | `SELECT * FROM programme_revision WHERE revision_id = ?` AND `SELECT current_revision_id FROM programme WHERE programme_id = ?` | `SupabaseDatabaseAdapter` -> `getSupabaseServerClient()` | **NO** (anon key only) | **YES** (`is_programme_member` policy grants active members) | `42501` (permission denied for table programme_revision / programme) |

### Final Mutation / RPC Boundary
- `ResidualAtomicRepository.createSiteDiary(...)` invoking `public.f1_create_site_diary_full_atomic` RPC.
- **Client Source**: `getSupabaseAuthenticatedClient(accessToken)` (Authenticated Request-Scoped: **YES**).
