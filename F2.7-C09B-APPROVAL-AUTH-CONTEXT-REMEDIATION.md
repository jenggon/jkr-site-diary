## Root Cause Analysis

Prior to remediation, `src/composition/approvalComposition.ts` defined top-level singleton repository instances using unauthenticated / anonymous Supabase clients:
- `revisionRepository = new ProgrammeRevisionRepository()` (defaulted to `SupabaseDatabaseAdapter` with `getSupabaseServerClient()`)
- `activityRepository = new ActivityRepository()` (defaulted to `SupabaseDatabaseAdapter` with `getSupabaseServerClient()`)
- `siteDiaryRepository` (imported as top-level singleton bound to `supabase` anon client)
- `progressRepository` (imported as top-level singleton bound to `supabase` anon client)
- `approvalRepository` (imported as top-level singleton bound to `supabase` anon client)

While `createApprovalService(accessToken)` injected `accessToken` into `ApprovalAtomicRepository`, the prerequisite reads in `ApprovalService.createApproval()` and `ApprovalService.updateApproval()` evaluated through these global anon instances.

Under C04 / C07 PostgreSQL RLS (`c07_programme_member_select_programme_revision`, `c07_programme_member_select_activity`, `c07_programme_member_select_site_diary`), tables require an authenticated caller with active `programme_membership`. Prerequisite queries made with the anonymous client failed with `42501 permission denied for table programme_revision` before ever reaching the authorized atomic mutation procedures.

## Code Remediations

The remediation follows a pure request-scoped dependency injection pattern with zero changes to database privileges, migrations, roles, or RLS:

### 1. `src/repositories/siteDiaryRepository.ts`
- Added interface `ISiteDiaryRepository` declaring all repository methods.
- Added factory `createSiteDiaryRepository(client: SupabaseClient = supabase): ISiteDiaryRepository` to bind operations to a request-scoped client.
- Preserved `export const siteDiaryRepository: ISiteDiaryRepository = createSiteDiaryRepository(supabase)` and all named function exports (`createSiteDiary`, `getSiteDiaryById`, etc.) for 100% backward compatibility.

### 2. `src/repositories/progressRepository.ts`
- Added interface `IProgressRepository` declaring all repository methods.
- Added factory `createProgressRepository(client: SupabaseClient = supabase): IProgressRepository` to bind operations to a request-scoped client.
- Preserved `export const progressRepository: IProgressRepository = createProgressRepository(supabase)` and all named function exports for backward compatibility.

### 3. `src/repositories/approvalRepository.ts`
- Added interface `IApprovalRepository` declaring all repository methods.
- Added factory `createApprovalRepository(client: SupabaseClient = supabase): IApprovalRepository` to bind operations to a request-scoped client.
- Preserved `export const approvalRepository: IApprovalRepository = createApprovalRepository(supabase)` and all named function exports for backward compatibility.

### 4. `src/services/approvalService.ts`
- Updated `IApprovalServiceDependencies` interface to use `ISiteDiaryRepository`, `IProgressRepository`, and `IApprovalRepository`.

### 5. `src/composition/approvalComposition.ts`
- Refactored `createApprovalService(accessToken?: string): IApprovalService`:
  ```typescript
  export function createApprovalService(accessToken?: string): IApprovalService {
    const client = accessToken ? getSupabaseAuthenticatedClient(accessToken) : getSupabaseServerClient();
    const adapter = new SupabaseDatabaseAdapter(client);

    return new ApprovalService({
      revisionRepository: new ProgrammeRevisionRepository(adapter),
      activityRepository: new ActivityRepository(adapter),
      siteDiaryRepository: createSiteDiaryRepository(client),
      progressRepository: createProgressRepository(client),
      approvalRepository: createApprovalRepository(client),
      atomicRepository: new ApprovalAtomicRepository(client),
      clock,
      logger,
    });
  }
  ```
- Created exactly ONE authenticated client per request, propagating it across all prerequisite read repositories and the atomic mutation boundary.
- Maintained legacy singleton export `export const approvalService: IApprovalService = createApprovalService()` for non-request contexts.
